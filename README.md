# 机票降价尖端模型 A1 — 研究与离线评估代码（首版公开包）

本仓库整理自内部「重训 / 影子评估」链路中**可公开**的文档与脱敏脚本骨架，方便外人提 Issue / PR，一起讨论特征、训练与离线评估方法。

## 本仓含什么

- **特征定案与说明**：A1 入模 46 列中文清单、特征候选池说明、S1/S2/S3 方法说明
- **脱敏后的脚本骨架**：S0 底表构建、S1 特征、S2 有用性、S3 训练主程序、干净口径评估模板、影子记账日更骨架等（路径改为环境变量 / 占位符）
- **少量指标与曲线摘要**：训练对照曲线、特征重要性等（非全量票价）
- `LICENSE`（MIT）、`.gitignore`、本说明与自检报告

## 本仓明确不含什么

- **不含模型权重**（如 LightGBM `model_A1_*.txt`）
- **不含全量票价 / 特征矩阵数据**（`*.parquet`、原始拉取包、服务器库）
- **不含密钥、远程登录私钥、现网登录信息**
- **不含线上推理服务配置、现网阈值热更新、真实订单或乘客信息**
- **不含尖端入选明细、影子账本逐单、真实航班名单**
- **不含**可还原经营规模的影子/对照累计数字表（`artifacts/results/` 仅留口径空壳说明）
- **故意未收录**三份尖端预测「结果」目录（见 `路径映射.md` 收录说明）

## 目录结构（摘要）

| 目录 | 用途 |
|------|------|
| `docs/` | 特征清单、各阶段说明、评估模板文档 |
| `scripts/` | 脱敏后的 Python/Shell 脚本骨架 |
| `configs/` | A 版定案、特征计划等 JSON |
| `artifacts/` | 核对摘要、训练曲线/指标；`results/` 仅为**方法示例空壳**（已去掉可还原经营规模的累计表） |
| `路径映射.md` | 源树相对路径 → 本仓路径 |
| `文件清单.csv` | 每个文件的来源分类与是否脱敏 |
| `自检报告.md` | 敏感词扫描结果 |

## 如何本地自备数据（占位）

脚本默认通过环境变量指向本地数据，例如：

```bash
export PROJECT_ROOT=/path/to/your/project
export PRED_ROOT=/path/to/pred
export AF_INCREMENTAL_DIR=/path/to/incremental_copies   # 可选
export TL2026_LOCAL_DIR=/path/to/timeline_local_copy     # 可选
export VENV_PYTHON=python3
```

你需要自备：观察日可见的日价底表、特征矩阵、以及（若跑训练）标签与划分说明。本仓**不提供**这些数据。

## 红线（研究仓约定）

- 本仓代码面向**离线研究 / 影子评估**，不提供生产部署步骤

## 标签定义（防泄露）

### 价格回归：还能降多少_元

- 窗 = 读法 B 可卖窗 **W=7**（观察日后 1..7 个日历日）。
- **只用观察日之后可见的未来价**：`还能降多少_元 = p0 − min(未来窗内价)`。
- 特征 = A1 的 46 列；**不含**未来价、未来标签、seats、禁止 42 列。
- 训练/验证/测试观察日切分与 A1 一致。

### 日期回归：触达降到线天数

- 降到线 = 价 ≤ p0−100 或 ≤ p0×0.85（同 S2/S3）。
- 标签 = 窗内**首次**触达降到线相对观察日的天数（1..7）。
- **未触达**：不删除样本，设**哨兵 = 8**（W+1，截尾）；说明见「触达状态」列。
- 特征同样只用观察日可见信息。

## 叠加方案族

| 方案族 | 规则 |
|---|---|
| 纯 A1 阈值出手基线 | 降分 ≥ 池阈值；结算=不提前出 |
| A1+价格回归辅助收 | 池内再要求 `预测_还能降多少 ≥ θ`；结算同基线 |
| A1+价格回归辅助出 | `预测_还能降多少 < θ` → 第 1 观察日提前出；否则基线 |
| A1+日期回归按预测日出手 | 到降到线立刻出；否则在 clip(round(预测天数),1,7) 有价日结算；预测≈哨兵则倾向满窗 |
| A1+日期回归晚触达提前出 | `预测天数 > θ` → 第 1 观察日提前出；否则基线 |
| 两者都用 | 价格过滤 ∩（按预测日 或 晚触达提前出） |
| 无模型对照 | 入场后第 N 个观察日必出（N=1..4） |

### VAL 选择规则（R）

1. 各族内 VAL **每单 k2** 最大；k2 差 &lt;1 元并列 → 更高门槛数值（更保守）。
2. **R3 族支持**：相对纯 A1 基线，Δ每单 k2≥5 **且** 每单 k1 不降；否则该族选定=基线。
3. **总选定** = 支持族中 VAL 每单 k2 最大者；若都无支持 → 纯 A1。
4. VAL 选择 JSON/过程表落盘并记 md5 后才读测试结算。
5. **重要读法**：R3 看的是**每单**尺子。价格「辅助收」会把池子收窄 → 每单常变好、**合计常变差**。经营若以**合计净省钱**为目标，不能把「每单 Δk2&gt;0」读成「能多赚」。

## 一句话结论（对现有 A1 起没起作用）

1. **尖端约 0.5%**：**日期回归不加**。价格回归「辅助收」（预测还能降≥400）把单子收到约 1/10，**每单**净省钱变好看，但**合计**净省钱明显变少 → **不是多赚，是更精更少**；若要保尖端合计利润，**不建议叠**。
2. **合计利润最大附近（约 33%）**：同上；过滤后约 1243 单，每单很亮、合计大减 → **保合计则不加**。仅当业务接受「大幅缩量换每单质量」时，才有离线参考意义（仍 ≠上线）。
3. **两者都用**未优于「只做价格过滤」的经营含义（按预测日结算在过滤子集上还略损每单）。

## 样本少 / 独立性披露

- 验证/测试各 **1 个观察日**（10-25 / 10-24）；路径依赖后续日价（可跨 exclude-from，只作路径）。
- 验证→测试无 gap 隔离；VAL 路径价覆盖测试期观察日 → **测试非完全独立**。
- 金额合计均为离线口径，**不是真实盈亏**。
- R3 以每单为主；合计读法见上表「人话」列，二者不可混谈。

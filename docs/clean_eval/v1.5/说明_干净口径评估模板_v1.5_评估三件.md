# 干净口径评估模板 v1.5（已 apply 评估三件）

大白话：在 v1.4 干净口径之上，**可选**打开「评估三件」。默认全关时，旧输出数字与 v1.4 一模一样。

## 并了什么
1. **三把尺子**（`--三件尺子`）：按距起飞天数分段；主指标=净省钱/综合利润（降价差价 − k×涨价亏损，k=1 与 k=2 并排）；对比「总是买(=0) / 总是等 / 占事后最优(真 p_min)」；命中率/精确率只作辅助。
2. **出手比例—净省钱曲线**（`--出手曲线`）：按天取前 X%；**选 X 只看净省钱峰**，不看命中率；正式选参须在 VAL，测试只报一次（完整流程用同目录 `run_eval_三件.py`）。
3. **前向打分日志**（`forward_score_log.py` / `--前向日志目录`）：只写评估目录；assert 拒绝现网路径；**现网写盘须另批**。

- 三个开关**默认全关** → 与 v1.4 同口径（差应为 0）。
- 需要三件时显式加 `--三件尺子` / `--出手曲线` / `--前向日志目录`。

## 3. 各步行数（口径，数字仅方法示意）

### 3.1 全航司主源
- 原始键×批次 → 剔通程（`len(航班号)=7`）→ 剔无效价 → 批内去重 → 折成每键每观察日一价 → 剔未走完的观察日 → 拆「回补键另存」与「非回补 dtd0..30 主表 / dtd31..50 对照」。
- 每天一价：每航司每观察日取当天**末批**；末批键数（只数 dtd≤30）不足当天最大批 70% 时改用最大批。本期观察窗内未触发该规则。
- 回补定义：键当天在某批出现，但不在当日选用批里，价格只能取当天更早批 → 标「回补」。主表剔除，另存回补表。
- 采集窗：观察日 <切换日 记「30天窗」；切换日记「切换日(30/50混)」；>切换日 记「50天窗」。切换日以前没有 dtd 31..50。

### 3.2 扩样本与五家对照
- 扩样本：剔通程 / 无效价 / dtd 范围外；价格异常（过高或偏离同键中位倍数）**只打标不删**，训练前再剔。
- 五家对照：dtd&lt;0 剔除；dtd&gt;30 保留并打标进对照表。

详细逐步计数 CSV 见本仓 `artifacts/checks/S0_底表/`（脱敏后公开的核对摘要）。

## 5. 口径对齐（方法结论）

### 5.1 口径差异
| 项 | 全航司主源 | 扩样本航管类 | 五家对照 |
|---|---|---|---|
| 价格字段 | 每批抓取展示价（整数；无舱位） | 源已折好的一天一价 | 源已折好的一天一价 |
| 一天一价怎么取 | 本 S0 按末批（≥70% 规则）重折 | 源库侧已折（取法细节在受保护脚本，本仓未收录） | 同左 |
| dtd | 起飞日 − 观察日 | 同左 | 同左 |
| 回补 | 有，已剔 | 源无此概念，记「否」 | 源无此概念 |

### 5.2 重叠键价差（结论性，非经营账）
- 全航司 vs 五家对照：同键价高度一致（完全相等占比约九成，显著降判定高度一致）→ 五家可作桥。
- 扩样本 vs 五家：相等率明显低于上者，均值偏高、近起飞更不一致 → **可作加/不加对照扩样本，不能直接无差别拼接**。
- 航管类与全航司主源直接重叠观察日常为 0，只能借五家桥接。

### 5.3 扩样本使用建议
1. 主表只用全航司；扩样本保留「数据源 / 子来源」，训练可分源加权；**评估、过门一律只用全航司**。
2. 少用跨源绝对价位特征；优先同键自身历史相对变化。
3. 扩样本标签噪声更大；远端 dtd（如 ≥14）更稳；偏差大的航司可先剔或单看。
4. 「只加当年新」与「再加上年」分两步对比。
5. 价格异常标记行训练前剔除。
6. 时间切分 gap≥7；观察期不重叠则无同键泄漏，但仍有季节混杂。

## 6. 注意事项（必读）

1. **无完整春运**；勿用于春运决策。
2. **季节 / 起飞月** 信号高度依赖扩样本，注意年份与来源混淆。
3. **已知空日批次**（如批 `202610301117` 起飞窗）：不当作真实空值；主表选用非事故批，并打标。
4. 采集窗切换日前后 dtd31..50 覆盖不对称。
5. 未走完的观察日（当天批数不足）不进主表。
6. 全航司主源可能无 dtd0；对照源可能有 dtd0 与少量 dtd&lt;0（已剔）。
7. 扩样本缺抓日不补（按既有授权）。

1. **尖端能多赚，全收单仍亏**：测试集「全收单」每单 k1≈+13.5、k2≈−21.2（涨价惩罚重）。模型靠「只推前约 0.5%」把钱捞回来：尖端每单 k2 大约 +160～+185，但召回只有约 1.4%（一天大约出手一千单量级），不是全面铺开。
2. **A版（全航司）**：默认 38（S2 短名单）+ 跨期对照后晋升 8 个 = **46 特征**（A1）。跨期候选 41 组，筛「综合分>0 且覆盖≥0.5」后只单加测了前 **15** 个；Δ验证峰k2≥1 才晋升。晋升：ly_route_depmonth_ratio / nflights / cap_ratio / price、ly_route_depweek_ratio、dest_avg_vol、dest_drop_rate、train_pct_pos。节假日绑死类（g1_days_to_tiaoxiu 等）一加就砸，已剔除。

## 口径（写死，同 v4b）

- 主切点 **读法B**：入场 dtd≥14；窗=7；降到线 = 价≤p0−100 或 ≤p0×0.85；涨到线对称 = 价≥p0+100 或 ≥p0×1.15。
- **不提前出（基线）**：入场后 7 个日历天内首次到降价线则按该价结算赚；否则按窗末价计涨亏。
- **提前出**：入场后逐日先看是否到降价线；未到且当日涨分≥θ → 按当日价提前结算（赚=0，亏=max(pd−p0,0)）。入场当日不算提前出。
- θ 网格与 R1–R5、无模型对照（第 N 日必出 / 随机提前出）同 v4b；**VAL 选择落盘并记 md5 后再读测试**。
- **入场行可预载、结算严格后算**：VAL/TEST 入场行可与路径/涨分一并载入（便于打分与扫池）；**测试结算结果**严格在 VAL 选择落盘并记 md5 **之后**才计算，不以测试结果改 θ。

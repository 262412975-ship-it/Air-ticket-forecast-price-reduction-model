# 影子记账结果目录（空壳）

本目录在公开包中**故意不收录**可还原经营规模的按日累计 / 降涨合计数字表与运行日志原文。

## 口径（方法示例，非经营真账）

- 主尺子：每单先扣固定成本再算 k1
- 读法 B：入场 dtd≥14、结算窗 7 天
- 双账阈值对照：尖端阈值 vs 宽档阈值（具体阈值数见训练定案 / 说明文档，不以本目录数字为准）
- 主累计**只含已结算**；未满窗挂账不入累计

复现请自备底表与特征后运行 `scripts/shadow_ledger/`；产出默认写本地 `账本/`（本仓 `.gitignore` 排除账本与逐单）。

> 声明：此处仅为方法占位；**不是**真实经营账，也不可外推为线上收益。
